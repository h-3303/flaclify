Get it.

One file, three steps
flaclify.flatpak

The bundle carries its own Music Player Daemon, so there is nothing to set up: point it at a folder and it plays. Wants the GNOME 50 runtime, which the install fetches from Flathub. All releases, with notes: github.com/h-3303/flaclify/releases.

NextWindows. The player is GTK4 and builds there; the daemon and the audio path are the work. Nothing to download yet.

  1. Open the downloaded flaclify.flatpak. Software, Discover and the like install it; from a terminal, flatpak install flaclify.flatpak. If Flathub is not yet a remote on your machine, flathub.org/setup is one line.
  2. Launch Flaclify. The first run asks where your music is (it offers your Music folder), whether each album has its own folder, and whether you want flacli beside it. flacli is optional: with it the player fetches music by name; without it, it is a player.
  3. The library scans while you look around. Ctrl+T changes the theme. Everything the first run set is under Preferences.

Already run MPD? Say so on the first page and give the socket or the host; the built-in daemon is then never started. Built from source instead: see Developers.

II

It changes its clothes.

A theme is one CSS file with a short header. It can recolour the window, square or round every corner, swap the typefaces, and bring its own icon set and album-art plate. Themes apply while the music plays. Pick one below; making your own takes an evening.
